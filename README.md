# KSWGD: Koopman Spectral Wasserstein Gradient Descent

This repository contains research notebooks and shared Python modules for testing **Koopman Spectral Wasserstein Gradient Descent (KSWGD)** on synthetic manifolds, multimodal stochastic systems, and latent-space PDE data.

## Main Notebooks

The cleaned core experiments are:

- `test_1_torus.ipynb`: runs the torus experiment and compares KSWGD with DMPS through final particle distributions, angular diagnostics, and KDE-style distribution plots.
- `test_2_quadruple_well.ipynb`: runs the quadruple-well experiment with the restored original DMPS and KSWGD settings, including particle snapshots, density heatmaps, well occupancy over time, movement rate, and KL divergence.
- `test_3_allen_cahn.ipynb`: runs latent-space KSWGD for the stochastic Allen-Cahn equation under two noise levels, `sigma=1.4142` and `sigma=0.1`, and visualizes decoded fields and pixel-value evolution.
- `test_1_torus_baseline_comparison.ipynb`: compares torus KSWGD with baseline particle methods such as ULA, SVGD, Matrix SVGD, RFM, and GFM.
- `test_2_quadruple_well_baseline_comparison.ipynb`: compares quadruple-well KSWGD/DMPS with baseline samplers such as ULA, MALA, HMC, and LDVI using the same target setup.
- `test_3_allen_cahn_baseline_comparison.ipynb`: compares Allen-Cahn latent KSWGD with baseline latent particle methods and summarizes method behavior across time.

Shared implementation lives in `systems.py`, `kswgd.py`, `dmps.py`, `baseline.py`, `experiment_plots.py`, and `plotting_utils.py`.

## Dependencies

The package list is maintained in `server_setup_packages.txt`. The main packages are:

- Core scientific stack: `numpy`, `scipy`, `matplotlib`, `pillow`, `opencv-python`, `psutil`
- Utilities: `tqdm`, `joblib`
- Machine learning and datasets: `torch`, `torchvision`, `scikit-learn`, `diffusers`, `datasets`
- Image restoration / generative-image utilities: `basicsr`, `realesrgan`, `gfpgan`
- Evaluation metrics: `pytorch-fid`, `lpips`
- Optional GPU acceleration for custom kernels: one CUDA-matched `cupy-cudaXXX` package, such as `cupy-cuda118` or `cupy-cuda121`

Install PyTorch with the command matching your CUDA version before installing the rest of the packages. For example:

```bash
python -m pip install --upgrade pip
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
pip install -r server_setup_packages.txt
```

If GPU custom kernels are needed, uncomment exactly one `cupy-cudaXXX` line in `server_setup_packages.txt` or install the matching package manually.

## Quick Start

Create and activate a virtual environment:

```bash
python -m venv /workspace/kswgd_env
source /workspace/kswgd_env/bin/activate
```

Install dependencies:

```bash
python -m pip install --upgrade pip
pip install -r server_setup_packages.txt
```

Register the Jupyter kernel:

```bash
python -m ipykernel install --user --name kswgd_env --display-name "Python (KSWGD)"
```

Run a notebook with the registered kernel, or execute it from the command line:

```bash
jupyter nbconvert --to notebook --execute --inplace \
  --ExecutePreprocessor.kernel_name=kswgd_env \
  --ExecutePreprocessor.timeout=-1 test_1_torus.ipynb
```

Generated figures are saved as both PNG and PDF under the `figures/` directory.

## Notes

- GPU is recommended for the Allen-Cahn latent experiments and for larger KSWGD runs.
- Some notebooks create checkpoint files such as `.torch` and `.jbl`; these are cached SDMD/Koopman model artifacts and can be regenerated by rerunning the relevant notebooks.
- `raw/` contains cached MNIST data used by old `test_3` notebooks, not by the six core notebooks above.
